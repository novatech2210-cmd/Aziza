# AZIZA Project Bootstrap Sequence

**MANDATORY FOR EVERY SESSION**

Before executing any commands, modifying any code, or starting any task, you MUST:

1. Read `engineering/PROJECT.md` to understand the system context.
2. Read `engineering/DEVELOPMENT_CHARTER.md` to review the immutable rules of this project.
3. Check `engineering/CURRENT_TASK.md` (or the equivalent `.gsd/` active task) to determine what work is authorized.
4. If the task involves architectural or cross-cutting changes, review `engineering/ARCHITECTURE.md` and `engineering/DECISION_LOG.md`.
5. Ensure the Repository Guardian agent validates the intended approach before any code is written.
